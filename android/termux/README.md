# Legacy Termux build script (developer reference only)

This folder contains the earlier external-Termux prototype. It is **not used by the current Horizon
launcher** and users must not be instructed to install Termux or grant RUN_COMMAND permissions.

The production direction is the Horizon-owned embedded runtime documented in
[../embedded-toolchain/README.md](../embedded-toolchain/README.md). The old script is retained
temporarily as a reference for the HNMod build sequence while that sequence is ported to the
embedded runtime. Do not use this script as the supported launcher workflow.
